PHPRegex regex-language-server
==============================

A Language Server for the regex patterns of PHP files: diagnostics, hovers, completions and code actions in any LSP editor.

```bash
composer require --dev php-regex/regex-language-server
```

Requires PHP 8.2+. MIT licensed.

Point your editor at `vendor/bin/regex-lsp`; the [LSP guide](https://github.com/php-regex/php-regex/blob/2.x/docs/guides/lsp.md#ide-configuration) holds configurations for VS Code, PhpStorm, Neovim, Vim and Emacs.

This package is part of [PHPRegex](https://github.com/php-regex/php-regex), released
with its siblings under one version number. Read
[the guide](https://github.com/php-regex/php-regex/blob/2.x/docs/guides/lsp.md) and
[the backward compatibility promise](https://github.com/php-regex/php-regex/blob/2.x/docs/reference/backward-compatibility.md).
