PHPRegex 2.x is a pre-release

The split packages are not on Packagist yet — install the monorepo until the 2.0.0 tag:

  1. Declare the repository in your composer.json:

    {"repositories":[{"type":"vcs","url":"https://github.com/php-regex/php-regex"}],"minimum-stability":"dev","prefer-stable":true}

  2. Require the monorepo package:

    composer require --dev php-regex/php-regex:2.x-dev

The monorepo ships every split package, with the vendor paths under vendor/php-regex/php-regex/src/. From the 2.0.0 release, composer require --dev {{ include.package }} works as-is.
