{% comment %} The home page's playground: a pattern, a subject, the PHP version, and what the real PHP and PCRE2 say about them, run in the visitor's browser by a PHP compiled to WebAssembly with PHPRegex loaded into it. Before the visitor asks for a run, the panels show the sample stored in _data/playground.json, rendered by the same script as a live result; the engine is downloaded on the first run gesture only, never on load. The data is embedded as JSON. Liquid writes "<" back when it re-encodes, so the include escapes it: a "<" could otherwise close the script element. A window: the title bar holds the PHP version, Run and the state; the body sets the fields and the answers on the left and the syntax tree on the right (one column under 1024px); the status bar at the bottom names the engine that answered. The pattern field is colored by the same answer — the engine's token spans, drawn in a mirror under the field, the code blocks' palette — and falls back to the field's own ink whenever the mirror does not render what the field says. The tree's pattern, piece by piece, wears the same colors inside its pieces. The notes and the credits sit under the window. {% endcomment %}
