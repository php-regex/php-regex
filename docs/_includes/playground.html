{% comment %} The home page's playground: a pattern, a subject, the PHP version, and what the real PHP and PCRE2 say about them, run in the visitor's browser by a PHP compiled to WebAssembly with PHPRegex loaded into it. Before the visitor asks for a run, the panels show the sample stored in _data/playground.json, rendered by the same script as a live result; the engine is downloaded on the first run gesture only, never on load. The data is embedded as JSON. Liquid writes "<" back when it re-encodes, so the include escapes it: a "<" could otherwise close the script element. Two columns on a wide screen: the fields and the answers on the left, the Pattern X-Ray on the right, always open; one column under 1024px. {% endcomment %}
