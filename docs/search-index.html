--- permalink: /search-index.json layout: none sitemap: false --- {% comment %} Search index for the docs search dialog. The dialog fetches this file once, on the first search, never at page load. One entry per documentation page, then one entry per section heading of that page; every field is escaped on its own so JSON quoting stays the engine's job. Excerpts: most pages enter the page list through the no-front-matter and readme-index generators and have not been converted to HTML yet when this file renders. Running the content through markdownify first yields clean text for those pages, and is idempotent for the rare page that was already converted earlier in the render order. Headings: the vocabulary a reader searches for — "atomic group", "possessive", a lint rule's name — lives in section titles, not in page titles. Each h2 and h3 of the rendered content becomes an entry of its own, anchored to its fragment. The page title it belongs to travels in a "context" field the dialog stores for display but never indexes: a query naming a page must match that page, not every section of it. Headings wearing the filter-toc or nav-title classes are skipped: a table of contents matches every query and answers none of them. A heading a Liquid include brings in (an install panel's "Installation") is invisible here — markdownify renders the page's own markdown only, and those pages keep their page-level entry. Sections: each entry also carries the sidebar section the page lives in, resolved against the navigation data (a group title from nav.yml or nav-tutorial.yml, matched by URL — the group's own URL counts too, so /guides/ belongs to Integrations). The first path segment, capitalized, is the fallback for a page the navigation does not list yet. Consumers use it as a result breadcrumb; a client that does not know the field simply ignores it. Not indexed: - the landing page (url "/"), the 404 page, and this file itself; - anything that is not an HTML page (the stylesheet, sitemap.xml, robots.txt, redirects.json) or is a redirect placeholder page. {% endcomment %} [ {% assign emitted = false %} {% for p in site.pages %} {% assign u = p.url %} {% assign ext = u | split: '.' | last %} {% assign last_char = u | slice: -1 %} {% assign html_page = false %} {% if last_char == '/' or ext == 'html' %} {% assign html_page = true %} {% endif %} {% unless html_page == false or p.layout == 'redirect' or u == '/' or u contains '404' or u contains 'search-index' %} {% assign section = '' %} {% for group in site.data.nav %} {% if group.url == u %} {% assign section = group.title %} {% endif %} {% for item in group.pages %} {% if item.url == u %} {% assign section = group.title %} {% endif %} {% endfor %} {% endfor %} {% for group in site.data['nav-tutorial'] %} {% if group.url == u %} {% assign section = group.title %} {% endif %} {% for item in group.pages %} {% if item.url == u %} {% assign section = group.title %} {% endif %} {% endfor %} {% endfor %} {% if section == '' %} {% assign head = u | remove_first: '/' | split: '/' | first %} {% if head %} {% assign section = head | capitalize %} {% endif %} {% endif %} {% if emitted %},{% endif %}{% assign emitted = true %} {% assign body = p.content %} {% if p.content contains '
