Excerpts: most pages enter the page list through the no-front-matter and readme-index generators and have not been converted to HTML yet when this file renders. Running the content through markdownify first yields clean text for those pages, and is idempotent for the rare page that was already converted earlier in the render order. Sections: each entry also carries the sidebar section the page lives in, resolved against the navigation data (a group title from nav.yml or nav-tutorial.yml, matched by URL — the group's own URL counts too, so /guides/ belongs to Integrations).
